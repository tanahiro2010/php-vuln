# 後半台本（50 分想定）

後半 100 枚のスライドに沿った講師台本。各スライドの目安時間、話す内容、実演操作を記載。

**準備**：休憩中に、両アプリの DB が汚れていないか確認。念のため `docker compose restart vulnerable secure` で DB を初期化しておくと安心。ブラウザは `http://127.0.0.1:5000/`（脆弱版）を開いた状態でスタート。

### S85. DB に保存された値も信用できない

### S93. 攻撃連鎖の振り返り

### S94. すべての根本原因
- 「一言で言うと、**ユーザー入力を SQL 文字列に直接結合していた**、これだけです」

### S95. 4 つの防御
- 「防御は 4 つ」
- 「プレースホルダ（最重要）、エラー文の統一（列挙防止）、入力検証（整数は整数だけ）、最小権限（DB ユーザーの権限を絞る）」
- 目安: 45 秒

### S96. プレースホルダを徹底する
- 「特に **プレースホルダを徹底する** ことが最重要」
- 「INSERT だけでなく SELECT/UPDATE/DELETE も」
- 「動的に列名や表名を組む場合は allow-list で」
- 「**文字列補間で SQL を作らない**（PHP なら `"...{$var}..."`、Python なら f-string）、これを徹底する」
- 目安: 45 秒
